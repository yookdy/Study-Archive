### 문법 작성 리스트

### ServerOpenCode
**코드 설명**
Node.js의 기본 내장 모듈인 `http`를 사용하여 가장 기초적인 웹 서버를 띄우고 포트를 열어 통신을 대기하는 실습입니다.

**사용된 문법**
* **모듈 호출 및 서버 생성:** `require('http')`, `http.createServer()`
* **서버 실행:** `server.listen()`

**결과물 및 이해**
* 백엔드 서버가 특정 포트(예: 3000)를 점유하고 클라이언트의 HTTP 요청을 기다리는 '대기 상태'의 기본 생명주기를 이해했습니다.

---

### URLPagecode
**코드 설명**
클라이언트가 요청한 URL 경로(Path)를 파악하여, 접속한 주소에 따라 각각 다른 문자열을 응답으로 내려주는 라우팅(Routing) 기초 실습입니다.

**사용된 문법**
* **요청 정보 확인:** `req.url`
* **조건문 분기:** `if (req.url === '...')`
* **응답 헤더 및 종료:** `res.setHeader()`, `res.end()`

**결과물 및 이해**
* `/`, `/about` 등 주소에 따라 서버가 다른 동작(데이터 반환)을 하도록 제어하는 API 창구 분리의 원리를 파악했습니다.

---

### HtmlServer
**코드 설명**
자바스크립트 코드 내부에 HTML을 하드코딩하지 않고, 외부에 작성된 `index.html` 파일을 서버가 읽어서 클라이언트에게 제공하는 실습입니다.

**사용된 문법**
* **파일 시스템 모듈:** `require('fs')`, `fs.readFile()`
* **HTML 응답 처리:** `res.writeHead(200, {'Content-Type': 'text/html; charset=utf-8'})`

**결과물 및 이해**
* 정적 파일(HTML 문서)을 서버가 로드하여 브라우저에 렌더링할 수 있도록 전달하는 파일 서빙(File Serving) 메커니즘을 이해했습니다.

---

### JsonFileServer
**코드 설명**
`data.json`이라는 외부 데이터 파일을 읽어와 웹 프론트엔드가 앱이나 웹 화면을 그릴 때 활용할 수 있도록 JSON API 형태로 데이터를 제공하는 실습입니다.

**사용된 문법**
* **JSON 포맷팅:** `JSON.stringify()`
* **JSON 응답 처리:** `res.setHeader('Content-Type', 'application/json')`

**결과물 및 이해**
* 현대 백엔드와 프론트엔드 간의 표준 데이터 교환 규격인 JSON 포맷의 구조와 네트워크 통신 방식을 학습했습니다.

---

### QueryServer & RouteServer
**코드 설명**
요청 URL 뒤에 붙는 쿼리스트링(`?key=value`)을 파싱하여 동적인 데이터를 처리하고, 다중 라우팅 구조를 심화하는 실습입니다.

**사용된 문법**
* **URL 객체 활용:** `new URL(req.url, 'http://localhost')`
* **쿼리 파라미터 추출:** `searchParams.get()`

**결과물 및 이해**
* 클라이언트가 서버로 전달하는 부가 정보(검색어, 필터 조건 등)를 백엔드에서 안전하게 추출하고 변수화하여 활용하는 방법을 습득했습니다.

---

### sqlServer
**코드 설명**
Node.js 서버와 TiDB 클라우드 데이터베이스를 최초로 연동하여, 실제 DB에 저장된 유저 데이터를 조회(SELECT)해 프론트엔드로 전달하는 실습입니다.

**사용된 문법**
* **DB 연동 및 환경변수:** `require('mysql2')`, `require('dotenv').config()`
* **연결 및 쿼리 실행:** `mysql.createConnection()`, `db.query()`

**결과물 및 이해**
* `.env` 파일을 통한 민감 정보(DB 주소, 비밀번호 등) 격리 방법을 배우고, 쿼리 결과를 JSON 형태로 변환해 반환하는 백엔드-DB 간의 필수 연동 사이클을 구축했습니다.

---

### sqlServer_advanced
**코드 설명**
DB 연결 유실(PROTOCOL_CONNECTION_LOST)을 막기 위해 커넥션 풀을 도입하고, DB 설정 파일(`database.js`)과 API 라우팅 서버(`server.js`)를 분리한 뒤, 기초적인 API 인증 키 보안을 적용한 실무형 서버 실습입니다.

**사용된 문법**
* **커넥션 풀 및 모듈화:** `mysql.createPool()`, `module.exports`
* **보안 및 상태 코드 제어:** 401(Unauthorized), 404(Not Found), 500(Internal Server Error) 분기 처리 및 에러 메시지 캡슐화

**결과물 및 이해**
* 단일 파일에 뭉쳐있던 코드를 역할별로 분리(관심사 분리)하여 유지보수성을 높였습니다. 
* URL 파라미터를 활용한 신분증(API Key) 검증 로직과 포괄적 에러 메시지 처리를 통해 실제 서비스 배포 시 필요한 안전한 서버 구조를 완성했습니다. 
* (추가 성과) DataGrip 툴을 연동하며 트랜잭션의 수동 커밋(Manual Commit)과 자동 커밋(Auto-Commit)의 차이를 명확히 이해하고 데이터 영구 저장 문제를 해결했습니다.
