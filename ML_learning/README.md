### 문법 작성 리스트

* `import re`: 정규표현식(Regular Expression) 모듈로, 복잡한 문자열 패턴을 검색하거나 분리할 때 사용합니다.
* `from collections import Counter`: 데이터의 개수를 빠르고 쉽게 세어주는 파이썬 내장 딕셔너리 확장 클래스입니다.
* `class`: 객체지향 프로그래밍에서 데이터와 함수를 하나의 단위로 묶는 틀(설계도)을 정의합니다.
* `__init__(self)`: 클래스로부터 객체가 생성될 때 자동으로 실행되는 초기화 메서드(생성자)입니다.
* `re.findall()`: 문자열에서 정규식 패턴과 일치하는 모든 부분을 찾아 리스트로 반환합니다.
* `dict.get(key, default)`: 딕셔너리에서 키(key)에 해당하는 값을 가져오며, 키가 없을 경우 에러 대신 지정한 기본값(default)을 반환합니다.
* `' '.join(list)`: 리스트 안의 문자열 요소들을 지정한 구분자(여기서는 공백)로 연결하여 하나의 문자열로 만듭니다.
* `if __name__ == "__main__":`: 해당 파이썬 파일이 모듈로 임포트되지 않고 직접 실행되었을 때만 아래의 코드를 동작시키도록 하는 조건문입니다.

---
* `import torch`: 딥러닝과 텐서 연산에 특화된 오픈소스 머신러닝 라이브러리인 파이토치(PyTorch)를 불러옵니다.
* `torch.tensor(data)`: 일반 파이썬 리스트나 배열을 파이토치의 다차원 행렬 구조인 텐서(Tensor)로 변환합니다. (`dtype` 속성으로 데이터 타입 지정 가능)
* `tensor.ndim` / `tensor.shape`: 텐서의 차원(Dimension) 수와 행렬의 크기(형태)를 반환합니다.
* `torch.rand(rows, cols)`: 0과 1 사이의 무작위 실수 난수로 채워진 지정된 크기의 텐서를 생성합니다. (주로 모델의 초기 가중치를 설정할 때 사용)
* `tensor.view(rows, cols)`: 텐서 내부의 실제 데이터는 유지한 채 텐서의 껍데기 형태(Shape)만 새로운 크기로 재배열합니다.
* `torch.matmul(a, b)`: 두 텐서 간의 행렬 곱셈(Matrix Multiplication)을 수행합니다. 파이썬에서는 `@` 연산자로 동일하게 축약하여 사용할 수 있습니다.

----
* `import torch.nn as nn`: 딥러닝 모델의 뼈대가 되는 계층(Layer), 활성화 함수, 손실 함수 등이 포함된 파이토치 신경망 모듈을 불러옵니다.
* `nn.Module`: 파이토치에서 모든 신경망 모델이 상속받아야 하는 기본 클래스(설계도)입니다.
* `super().__init__()`: 부모 클래스인 `nn.Module`의 초기화 메서드를 실행하여 모델의 구조를 설정할 준비를 합니다.
* `nn.Linear(in, out)`: 입력(in)과 출력(out)의 크기를 지정하면 내부에 자동으로 가중치(Weight)와 편향(Bias) 텐서를 생성하여 선형 변환($Y = XW + b$)을 수행하는 신경망 계층입니다.
* `nn.ReLU()`: 음수는 0으로, 양수는 그대로 반환하여 모델에 비선형성을 더해주는 대표적인 활성화 함수입니다.
* `forward(self, x)`: 모델에 데이터가 입력되었을 때, 데이터를 각 계층에 순서대로 통과시키는 연산 흐름을 정의하는 메서드입니다.
* `torch.manual_seed()`: 난수 생성기의 시드(Seed)를 고정하여, 코드를 다시 실행해도 항상 동일한 무작위 가중치와 결과를 얻도록 합니다.





### 01_simple_Tokenizer

**코드 설명**
LLM이 자연어를 이해하기 위한 첫 단계인 텍스트 토큰화(Tokenization)와 단어 사전(Vocabulary) 구축 과정을 파이썬 표준 라이브러리만을 사용하여 객체지향적으로 구현한 기초 실습입니다.

**사용된 문법**
* **모듈 및 클래스:** `import re`, `Counter`, `class`, `__init__`
* **문자열 및 정규식 처리:** `re.findall()`, `text.lower()`, `join()`
* **자료구조 활용:** `Dictionary`, `List Comprehension`
* **실행 제어:** `if __name__ == "__main__":`

**결과물 및 이해**
* 정규식을 이용해 입력된 텍스트를 단어와 기호 단위로 깔끔하게 분리(`train` 단계)합니다.
* `Counter`를 활용해 등장 빈도순으로 고유한 정수 ID를 부여하여 단어장(`vocab`)과 역방향 단어장(`inverse_vocab`)을 성공적으로 구축했습니다.
* 한 번도 본 적 없는 단어를 처리하기 위해 0번 인덱스에 특수 토큰인 `<UNK>`(Unknown)를 강제로 할당하는 LLM의 필수 예외 처리 기법을 적용했습니다.
* 새로운 테스트 문장을 입력하면 모델이 연산 가능한 숫자 배열로 변환(`encode`)하고, 이를 다시 사람이 읽을 수 있는 텍스트로 복원(`decode`)하는 과정을 확인했습니다.



### 02_PyTorch_MatrixOperations

**코드 설명**
LLM의 '뇌'를 구성하는 데이터 구조인 텐서(Tensor)를 생성하고, 인공신경망의 핵심 연산인 차원 변환과 행렬 곱셈을 파이토치(PyTorch)를 이용해 수행해 보는 실습입니다.

**사용된 문법**
* **텐서 생성 및 초기화:** `torch.tensor()`, `torch.rand()`, `dtype=torch.float32`
* **텐서 속성 확인:** `tensor.ndim`, `tensor.shape`
* **텐서 조작 및 연산:** `tensor.view()`, `torch.matmul()`, `@` (행렬 곱셈 연산자)

**결과물 및 이해**
* 기본 파이썬 리스트를 2D 텐서(다차원 행렬)로 변환하고, `shape`를 통해 행렬의 크기가 `[2, 2]` 형태로 구성됨을 확인했습니다.
* 딥러닝 모델이 처음 학습을 시작할 때 가지는 초기 가중치 상태를 모사하여 `[2, 3]` 형태의 무작위 난수 텐서를 생성했습니다.
* `view()` 함수를 사용하여 데이터의 손실 없이 2x3 행렬을 3x2 행렬로 구조를 변경해 보며, 모델 내부의 데이터 흐름(Shape)을 맞추는 방법을 실습했습니다.
* `matmul()`과 `@` 연산자를 활용하여 두 행렬 간의 내적 연산(행렬 곱셈)을 수행하였고, 이것이 챗GPT 등 LLM 내부에서 일어나는 가장 기초적이고 핵심적인 연산임을 이해했습니다.


### 03_simple_neural_network

**코드 설명**
파이토치의 `nn.Module`을 상속받아 딥러닝 모델의 기본 뼈대를 만들고, 선형 계층(`nn.Linear`)과 활성화 함수(`ReLU`)를 통과하는 데이터의 흐름을 구현해 본 실습입니다.

**사용된 문법**
* **모델 뼈대 구축:** `class`, `nn.Module`, `super().__init__()`
* **신경망 계층 및 함수:** `nn.Linear()`, `nn.ReLU()`
* **연산 흐름 제어:** `forward()`
* **기타:** `torch.manual_seed()` (난수 고정), `.detach()` (그래디언트 추적 분리 출력)

**결과물 및 이해**
*  이전 코드에서 직접 수학적으로 계산했던 행렬 곱셈과 덧셈 연산($Y = XW + b$)을 파이토치의 `nn.Linear` 모듈이 가중치(`weight`)와 편향(`bias`)을 자동 생성하여 손쉽게 처리함을 확인했습니다.
* `forward` 함수를 통해 입력 데이터가 선형 계층과 활성화 함수를 순차적으로 통과하는 흐름(파이프라인)을 객체지향적으로 설계했습니다.
* `ReLU` 활성화 함수를 거치며 선형 연산의 결과 중 음수 값이 모두 0으로 처리되는 것을 눈으로 확인하고, 인공신경망에 비선형성(Non-linearity)이 추가되는 원리를 이해했습니다.

**실행 순서도 (Data Flow)**
1. **메인 블록 진입**: 스크립트 실행 시 `if __name__ == "__main__":` 블록으로 진입하여 무작위 난수 시드 고정
2. **모델 조립**: `model = SimpleNetwork()` 코드 실행 ➡️ `__init__` 함수로 점프하여 선형 계층(`Linear`)과 활성화 함수(`ReLU`) 부품 초기화
3. **데이터 준비**: 모델에 입력할 가상의 다차원 텐서 데이터(`input_data`) 생성
4. **데이터 입력 (호출)**: `model(input_data)` 코드를 통해 객체를 함수처럼 호출 ➡️ 내부에서 자동으로 `forward(x)` 함수로 점프
5. **순전파(Forward) 연산**: 입력 데이터 `x` ➡️ `linear_layer` (행렬 곱셈 연산) ➡️ `relu` (음수 필터링 비선형 변환) ➡️ 최종 결과 반환 및 종료
