### 문법 작성 리스트

* `import re`: 정규표현식(Regular Expression) 모듈로, 복잡한 문자열 패턴을 검색하거나 분리할 때 사용합니다.
* `from collections import Counter`: 데이터의 개수를 빠르고 쉽게 세어주는 파이썬 내장 딕셔너리 확장 클래스입니다.
* `class`: 객체지향 프로그래밍에서 데이터와 함수를 하나의 단위로 묶는 틀(설계도)을 정의합니다.
* `__init__(self)`: 클래스로부터 객체가 생성될 때 자동으로 실행되는 초기화 메서드(생성자)입니다.
* `re.findall()`: 문자열에서 정규식 패턴과 일치하는 모든 부분을 찾아 리스트로 반환합니다.
* `dict.get(key, default)`: 딕셔너리에서 키(key)에 해당하는 값을 가져오며, 키가 없을 경우 에러 대신 지정한 기본값(default)을 반환합니다.
* `' '.join(list)`: 리스트 안의 문자열 요소들을 지정한 구분자(여기서는 공백)로 연결하여 하나의 문자열로 만듭니다.
* `if __name__ == "__main__":`: 해당 파이썬 파일이 모듈로 임포트되지 않고 직접 실행되었을 때만 아래의 코드를 동작시키도록 하는 조건문입니다.







### 01_simple_Tokenizer

**코드 설명**
LLM이 자연어를 이해하기 위한 첫 단계인 텍스트 토큰화(Tokenization)와 단어 사전(Vocabulary) 구축 과정을 파이썬 표준 라이브러리만을 사용하여 객체지향적으로 구현한 기초 실습입니다.

**사용된 문법**
* **모듈 및 클래스:** `import re`, `Counter`, `class`, `__init__`
* **문자열 및 정규식 처리:** `re.findall()`, `text.lower()`, `join()`
* **자료구조 활용:** `Dictionary`, `List Comprehension`
* **실행 제어:** `if __name__ == "__main__":`

**결과물 및 이해**
* 정규식을 이용해 입력된 텍스트를 단어와 기호 단위로 깔끔하게 분리(`train` 단계)합니다.
* `Counter`를 활용해 등장 빈도순으로 고유한 정수 ID를 부여하여 단어장(`vocab`)과 역방향 단어장(`inverse_vocab`)을 성공적으로 구축했습니다.
* 한 번도 본 적 없는 단어를 처리하기 위해 0번 인덱스에 특수 토큰인 `<UNK>`(Unknown)를 강제로 할당하는 LLM의 필수 예외 처리 기법을 적용했습니다.
* 새로운 테스트 문장을 입력하면 모델이 연산 가능한 숫자 배열로 변환(`encode`)하고, 이를 다시 사람이 읽을 수 있는 텍스트로 복원(`decode`)하는 과정을 확인했습니다.
