# server
- 네트위크 를 통해 client에 서버스를 제공하는 컴퓨터 시스템
- 데이터 저장 처리, 관리, 응용 프로그램을 제공등 여러가지 기능 수행

# client
- 서버로부터 요청하고 받는 컴퓨터 시스템 또는 소프트웨어 응용 프로그램
- 사용자가 직접 사용하는 장치나 특정 응용 프로그램을 지칭

# server, client ex
- 웹 서버와 브라우저
    웹 브라우저(클라이언트)는 웹 서버에 HTTP 요청
    웹 서버는 해당 요청을 처리하여 HTML 문서를 반환
    
- 파일 서버와 파일 공유 클라이언트
    네트워크를 통해 파일을 저장하고 관리
    클라이언트는 파일 서버에 접속하여 파일을 업로드하거나 다운로드
    
## 서버와 클라이언트 구조와 동작

# Request, Response
    각각은 클라이언트쪽에서 요청하고 받는 동작
    HTTP, HTTPS와 같은 프로토콜을 사용을 함

# Resquest 메세지 구조
- Start Line
    HTTP 메서드 + 요청 자원 경로 + HTTP 버전 순서로 띄어쓰기로 구분해 기록
- Headers
    요청 자체에 대한 추가 정보(호스트 주소, 데이터 타입 등)를 Key: Value 형태로 기록
- Blank Line
    구분선 역할을 하는 빈 줄
    헤더(Headers)의 끝과 본문(Body)의 시작을 컴퓨터가 구별
- Body
    실제 데이터가 들어가는 영역

# Resquest 메서드 
- Get: 서버에 저장된 데이터를 조회
- Post: 서버에 새로운 데이터를 생성하거나 전송하여 등록
- Put: 서버의 데이터를 전체 수정
- Patch: 서버의 데이터를 일부 수정
- Delete: 서버의 데이터를 삭제
