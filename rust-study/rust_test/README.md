# Rust 문법 누적 리스트

현재까지 실습하며 학습한 전체 Rust 문법과 키워드입니다. 새로운 코드를 작성할 때마다 이곳에 추가됩니다.

* `fn main()`: Rust 프로그램이 실행될 때 가장 먼저 호출되는 진입점(Entry point) 함수입니다.
* `println!()`: 콘솔 화면에 문자열이나 변수 값을 출력할 때 사용하는 매크로입니다. (일반 함수와 달리 끝에 `!`가 붙습니다.)
* `let`: 값을 변경할 수 없는 불변(Immutable) 변수를 선언할 때 사용합니다.
* `let mut`: 이후에 값을 자유롭게 변경할 수 있는 가변(Mutable) 변수를 선언할 때 사용합니다.

---

## 실습 기록

### 01_basic

**코드 설명**
Rust의 가장 기본적인 출력 방식과 변수 선언 원칙을 확인하는 기초 실습입니다. 다른 언어와 달리 변수가 기본적으로 불변(Immutable)으로 취급된다는 점을 중점적으로 테스트했습니다.

**사용된 문법**
* **함수 및 출력:** `fn main()`, `println!()`
* **변수 선언:** `let`, `let mut`

**결과물 및 이해**
* `println!` 매크로를 사용하여 "Hello, World!" 문자열이 콘솔에 정상적으로 출력됨을 확인했습니다.
* `let`으로 선언한 변수는 기본적으로 값을 바꿀 수 없으며, 값을 덮어쓰려 할 경우 컴파일 에러가 발생함을 이해했습니다.
* 값을 변경해야 하는 경우 명시적으로 `mut` 키워드를 붙여야 하며, 이를 통해 Rust가 기본적으로 코드의 안전성을 강력하게 통제하고 있음을 체감했습니다.
