# HTML 문법 누적 리스트

현재까지 실습하며 학습한 전체 HTML 태그와 문법입니다. 새로운 코드를 작성할 때마다 이곳에 추가됩니다.

* `<!DOCTYPE html>`: 최신 웹 표준인 HTML5 문서임을 선언합니다.
* `<html>`: HTML 문서의 전체 범위를 지정합니다.
* `<head>`: 브라우저에 표시되지 않는 문서의 설정(메타데이터, 타이틀, 스타일 등)을 담습니다.
* `<meta>`: 문자 인코딩(UTF-8)이나 모바일 화면 배율(viewport) 등 문서의 주요 속성을 설정합니다.
* `<title>`: 웹 브라우저 탭에 표시되는 페이지 제목입니다.
* `<style>`: 문서 내부에 직접 CSS 디자인(글꼴, 색상, 여백 등)을 적용할 때 사용합니다.
* `<body>`: 텍스트, 이미지 등 사용자가 브라우저를 통해 실제로 보게 되는 모든 콘텐츠가 위치합니다.
* `<div>`: 여러 요소를 하나의 박스로 묶거나 구역을 나눌 때 사용하는 범용 블록 태그입니다.
* `<h1>` ~ `<h6>`: 문서의 주요 제목 및 부제목을 나타냅니다.
* `<p>`: 일반적인 텍스트 단락을 나눕니다.
* `<ul>`: 순서 기호(점)가 없는 목록 영역을 만듭니다.
* `<li>`: 목록(`<ul>` 또는 `<ol>`) 내부의 개별 항목을 나타냅니다.
* `<strong>`: 문맥상 중요한 텍스트를 굵은 글씨로 강조합니다.
* `<a>`: 클릭 시 다른 웹페이지로 이동하는 하이퍼링크를 생성합니다 (`href` 속성으로 주소 지정, `target="_blank"`로 새 창 열기).
* `<form>`: 사용자 입력을 수집하여 전송하는 폼 영역을 정의합니다 (`action`, `method` 속성 사용).
* `<label>`: 폼 컨트롤의 이름표 역할을 하며, `for` 속성으로 입력 요소의 `id`와 연결합니다.
* `<input>`: 텍스트, 이메일 등 단일 행 데이터를 입력받습니다 (`type`, `placeholder`, `required` 속성 사용).
* `<select>`: 드롭다운 형태의 선택 목록 상자를 생성합니다.
* `<option>`: `<select>` 내에서 선택 가능한 개별 항목을 정의합니다 (`value` 속성 사용).
* `<textarea>`: 여러 줄의 긴 텍스트를 입력받는 텍스트 영역을 생성합니다 (`rows` 속성 사용).
* `<button>`: 클릭 가능한 버튼을 생성합니다 (`type="submit"`으로 폼 양식 제출).
* `<header>`: 웹페이지나 특정 구역의 최상단 머리말(로고, 주요 제목 등) 영역을 정의합니다.
* `<nav>`: 다른 페이지로 이동할 수 있는 주요 네비게이션 링크(메뉴)들을 모아두는 영역입니다.
* `<main>`: 웹문서의 핵심이 되는 주요 콘텐츠 영역을 지정합니다 (페이지당 한 번만 사용 권장).
* `<section>`: 주제별로 콘텐츠를 묶어주는 논리적인 구역을 나눕니다.
* `<footer>`: 웹페이지의 최하단 꼬리말(저작권 정보, 연락처 등) 영역을 정의합니다.

## 실습 기록

### 01-basic

**코드 설명**
웹페이지를 구성하는 필수 기본 뼈대(HTML5 구조)를 작성하고, 제목, 단락, 목록, 링크 등 가장 자주 쓰이는 핵심 텍스트 요소들을 배치하여 브라우저에 어떻게 렌더링되는지 확인하는 기초 실습입니다.

**사용된 문법**
* **문서 구조:** `<!DOCTYPE html>`, `<html>`, `<head>`, `<meta>`, `<title>`, `<body>`
* **디자인 및 레이아웃:** `<style>`, `<div>`
* **텍스트 및 콘텐츠:** `<h1>`, `<h2>`, `<p>`, `<ul>`, `<li>`, `<strong>`, `<a>`

**결과물 및 이해**
* 브라우저 탭 이름이 "웹 개발 연습"으로 올바르게 표시됩니다.
* 화면 최상단에 진한 굵은 글씨의 메인 제목(`<h1>`)이 렌더링됩니다.
* CSS가 적용된 회색 배경과 둥근 테두리 박스 영역(`<div>`) 안에 부제목(`<h2>`)과 설명 단락(`<p>`)이 그룹화되어 배치됩니다.
* 점(`•`)으로 시작하는 3개의 목록(`<li>`)이 나열되며, `<strong>` 태그로 묶은 텍스트는 굵게 강조되어 보입니다.
* 목록의 마지막 항목에는 클릭 시 지정된 주소(구글)로 이동하는 파란색 링크(`<a>`)가 생성되며, `target="_blank"` 속성에 의해 새 탭에서 열립니다.

### 02-form-basic

**코드 설명**
사용자로부터 다양한 형태의 입력 데이터를 수집할 수 있는 폼(Form) 요소들을 작성하고, CSS를 이용해 입력창의 크기와 요소 간의 간격(`margin`, `padding`)을 정렬해보는 실습입니다.

**사용된 문법**
* **폼 레이아웃:** `<form>`, `<label>`, `<button>`
* **입력 컨트롤:** `<input>`, `<select>`, `<option>`, `<textarea>`
* **주요 CSS 속성:** `margin`(바깥 여백), `padding`(안쪽 여백), `box-sizing`, `width`

**결과물 및 이해**
* 텍스트, 이메일, 드롭다운, 긴 글(다중 행) 입력란이 일정한 가로 길이(`width: 100%`)와 패딩을 가진 깔끔한 형태로 렌더링됩니다.
* `<label>`의 `for` 속성과 입력창의 `id`가 연결되어, 라벨 글자를 클릭해도 해당 입력창에 포커스가 자동으로 맞춰집니다.
* 크롬과 사파리 등 브라우저에 따라 폼 요소(드롭다운 화살표 등)의 기본 렌더링 디자인이 다르게 보일 수 있음을 확인했습니다.
* CSS의 `margin-bottom`을 활용해 `.form-group`으로 묶인 각 입력 항목(`<div>`) 간의 세로 간격을 띄웠습니다.
* 하단 "제출" 버튼 클릭 시 폼 제출 기능이 동작합니다.

### 03-semantic-layout

**코드 설명**
과거처럼 모든 구역을 `<div>`로만 나누지 않고, HTML5의 시맨틱(의미론적) 태그를 활용하여 웹페이지의 상단, 메뉴, 본문, 하단 영역을 구조적으로 명확하게 분리해 보는 실습입니다.

**사용된 문법**
* **시맨틱 구조:** `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`
* **주요 CSS 속성:** `margin: 0 auto`(가운데 정렬), `text-decoration: none`(링크 밑줄 제거), `box-shadow`(그림자 효과), `hover`(마우스 오버 효과)

**결과물 및 이해**
* 최상단에 어두운 배경의 헤더(`<header>`)와 메뉴 바(`<nav>`)가 화면 가로 전체에 배치됩니다.
* 메뉴 링크(`<a>`)에 마우스를 올리면 `:hover` 속성에 의해 글자 색상이 주황색으로 변하여 시각적인 피드백을 줍니다.
* 본문 콘텐츠가 들어가는 `<main>` 영역은 화면 중앙에 정렬(`margin: 0 auto`)되고, 부드러운 그림자(`box-shadow`)가 적용되어 배경과 분리된 종이 문서 같은 느낌을 줍니다.
* 본문 내의 두 가지 글은 각각 독립적인 `<section>`으로 묶여 하단 테두리 선으로 깔끔하게 구분됩니다.
* 페이지 맨 아래에는 저작권 정보가 포함된 어두운 색상의 푸터(`<footer>`)가 렌더링됩니다.
